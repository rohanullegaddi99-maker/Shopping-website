# Smart Online Shopping Website

A full-stack, modern e-commerce application featuring AI-inspired mood-based filtering, responsive design, and a scalable architecture. 

## Features Implemented
- **Frontend**: React.js with Vite, styled with Tailwind CSS (Modern, mobile-first design, fluid animations).
- **Backend**: Java Spring Boot 3.2.5 REST API.
- **Database**: MySQL mapping with Hibernate/JPA.
- **Security**: JWT-based Authentication System (Register, Login).
- **Products & Mood Filtering**: View products dynamically based on selected mood (Happy, Fitness, Casual, Professional, Relaxed).
- **Routing**: React Router DOM (Home, Login, Register, Cart, Product Details).

## Step-by-Step Setup Instructions

### Prerequisites
1. **Node.js** (v18+)
2. **Java JDK** (v21 or v17)
3. **MySQL Server** (Running on port 3306)

### 1. Database Setup
Ensure you have MySQL running. Create the database:
```sql
CREATE DATABASE IF NOT EXISTS shopping_db;
```
*(The tables `users` and `products` will be auto-generated by Hibernate, and sample products will be automatically seeded on startup!)*

### 2. Backend Setup
1. Open a terminal and navigate to the backend folder:
   ```bash
   cd "d:\shopping website\backend"
   ```
2. Verify `src/main/resources/application.properties` has your correct MySQL `root` username and password. Currently, it defaults to:
   ```properties
   spring.datasource.username=root
   spring.datasource.password=root
   ```
3. Build and run the Spring Boot application using Maven:
   ```bash
   # On Windows
   .\mvnw.cmd spring-boot:run
   ```
   *The backend will start on `http://localhost:8080`.*

### 3. Frontend Setup
1. Open a new terminal and navigate to the frontend folder:
   ```bash
   cd "d:\shopping website\frontend"
   ```
2. Run the development server:
   ```bash
   npm run dev
   ```
   *The frontend will start on `http://localhost:5173`.*

## Basic API Documentation (Backend)

### Authentication Endpoints
- `POST /api/auth/register`
  - Body: `{ "name": "John Doe", "email": "john@example.com", "password": "password" }`
  - Returns: JWT Token and user info.
- `POST /api/auth/login`
  - Body: `{ "email": "john@example.com", "password": "password" }`
  - Returns: JWT Token.

### Product Endpoints
- `GET /api/products` (Public)
  - Query Params: `?category={category}`, `?mood={mood}`, `?search={search}`
  - Returns: List of products.
- `GET /api/products/{id}` (Public)
  - Returns: Single product details.
